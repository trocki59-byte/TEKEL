# Bayi Yönetim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Troçki Studio açılışlı, ortak veritabanlı Türkçe bayi yönetimi.
**Architecture:** Vinext React arayüzü, kimlik denetimli API, D1 sürüm denetimli JSON durum kaydı. İş kuralları framework bağımsız modülde.
**Tech Stack:** React, TypeScript, Vinext, Cloudflare D1, Node test runner.
**Spec:** ../specs/2026-10-28-bayi-design.md

## Global Constraints
- Koyu lacivert/mavi, telefon ve bilgisayar.
- Para kuruş, stok paket, barkodlar uydurulmaz.
- Özel hesap erişimi, eşzamanlı yazma çatışmaları reddedilir.

## Review Focus
- Karton miktarı stok sınırını aşamaz.
- Aynı anda iki cihaz eski stokla satış yapamaz.
- Veresiye tahsilatı bakiyeyi aşamaz.
- Geçersiz yedek mevcut kaydı bozmaz.
- Fiyat değişimi eski satış kârını değiştirmez.
